# GX-ULTRA — Casio-подобный циферблат для Apple Watch Ultra 3

Полноэкранный «модуль» в духе Casio G-Shock / Pro Trek, где **каждый элемент —
рабочий прибор**, а не картинка: сегменты рисуются вручную (видны выключенные
«призрачные» сегменты, как на настоящем STN-стекле), данные приходят из
HealthKit, CoreMotion, CoreLocation, WeatherKit и датчика погружения Ultra.

## Важное ограничение (честно и сразу)

Apple **не открывает API для сторонних циферблатов**. Никто, кроме Apple, не может
добавить свой watch face в список. Поэтому здесь три уровня подмены:

1. **Приложение-циферблат** (основное). Ставится на часы, открывается с Action
   Button или с Dock, поддерживает Always-On Display. Поведение близко к
   циферблату: опустил руку — экран гаснет в «ночной» LCD-кадр, поднял — снова
   живые цифры. Чтобы часы не выкидывали в стандартный циферблат, поставь
   *Настройки → Основные → Возврат к циферблату → Через 1 час* (или «Никогда»
   для этого приложения).
2. **Осложнения GX-ULTRA** (WidgetKit) — те же LCD-модули на штатных циферблатах
   Apple (Modular Ultra, Инфограф и т.д.), если хочется гибрид.
3. **Фон для циферблата «Фото»** — `docs/watchface-preview.html` открывается в
   браузере и снимается скриншотом 410×502; получается статичная «Casio-подложка»
   с настоящими осложнениями по углам.

## Что на экране и что оно реально делает

| Элемент | Данные | Действие |
|---|---|---|
| Статусная строка `ALM SIG LAP` | будильники, часовой сигнал, запущенный секундомер | загораются только когда состояние реально активно |
| Батарея (5 ячеек + %) | `WKInterfaceDevice` | при зарядке появляется `CHG`, ниже 15% шкала краснеет |
| Дата `MON 9-15 WK38` | календарь | номер ISO-недели |
| Большие часы | системное время, 12/24ч | тап по стеклу = кнопка LIGHT (EL-подсветка + щелчок) |
| Секунды (акцентом) | | скрываются в Always-On, чтобы не жечь OLED |
| Окно данных | пульс / шаги / высота / температура / батарея / ккал | тап — следующий параметр, кнопка `DATA` — то же |
| Шкалы `MOV EXE STD` | кольца активности из HealthKit | перевыполнение подсвечивается акцентом; тап → режим BPM |
| Кнопки снизу | `MODE · действие · ADJ · LIGHT` | подписи меняются под режим, как гравировка на корпусе G-Shock |

## Режимы (колёсико Digital Crown или кнопка MODE)

- **TIME** — основной экран.
- **BPM** — пульс, пульс покоя, HRV, индекс нагрузки (`CALM/LIGHT/WORK/HARD`),
  шаги, дистанция, часовая гистограмма пульса.
- **STW** — секундомер с сотыми, круги, сплит и средний круг; переживает
  перезапуск (считается от абсолютной метки времени).
- **TMR** — таймер с пресетами 1/3/5/10/25/60 мин, повтором и локальным
  уведомлением (срабатывает с погашенным экраном).
- **ALM** — будильники (тап — вкл/выкл, долгое нажатие — правка ±5 мин) и
  часовой сигнал SIG.
- **DUAL** — второй часовой пояс с разницей `+2H`, домашнее время рядом.
- **SUN** — восход, закат, солнечный полдень, золотой час, длина дня, шкала
  прожитого светового дня и фаза Луны с отрисованным терминатором.
  Считается локально (упрощённые формулы NOAA) — работает без сети.
- **CMP** — компас: вращающаяся картушка, азимут, румб, `MARK` — запомнить
  направление и расстояние до точки (мини-Backtrack).
- **ALTI** — барометрическая высота, набор от нулевой отметки (`ZERO`),
  давление в гПа, гистограмма тренда и простой прогноз `CLEAR/STABLE/RAIN`.
- **DIVE** — только Ultra: глубина, максимум за заплыв, температура воды
  (`CMWaterSubmersionManager`). Не дайв-компьютер, а индикатор.
- **WKT** — быстрый старт тренировки (бег/ходьба/вело/поход/зал/плавание)
  с записью в Здоровье и живыми метриками.

## Темы LCD

`DW-5600` (позитивный серо-зелёный), `NEGATIVE` (светлые сегменты на чёрном),
`MUDMASTER` (олива + янтарь), `FROGMAN` (бирюза), `NIGHT` (только красный — не
сбивает адаптацию глаза в темноте). Меняется в `ADJ`.

## Управление

- **Тап по стеклу** — подсветка LIGHT.
- **Digital Crown** — перебор режимов с тактильными щелчками.
- **Двойной тап пальцами** (watchOS 11+) — главное действие режима:
  старт/стоп секундомера, пауза тренировки, `MARK` в компасе, `ZERO` в альтиметре.
- **Боковая кнопка «Действие»** (Ultra) — через App Intents:
  «Секундомер: старт/стоп», «Подсветка», «Компас: отметить направление»,
  «Открыть режим …». Настраивается в *Настройки → Кнопка «Действие» → Ярлык*.

## Сборка

```bash
brew install xcodegen
cd GXUltraFace
xcodegen generate          # создаст GXUltra.xcodeproj
open GXUltra.xcodeproj
```

Дальше в Xcode:

1. В `project.yml` (или в Signing & Capabilities) подставь свой `DEVELOPMENT_TEAM`.
2. Возможности: **HealthKit**, **App Groups** (`group.com.easylist.gxultra`),
   **WeatherKit** (если нет платного аккаунта — модуль температуры просто
   покажет `--`, остальное работает), **Background Modes → Workout processing**.
3. Схему `GXUltraWatch` собрать на часы (симулятор Ultra 49mm тоже подойдёт,
   но без пульса, барометра и датчика воды).

Без XcodeGen: создай в Xcode watchOS App + Widget Extension и перетащи папки
`Sources/GXUltraWatch` и `Sources/GXUltraComplications` в соответствующие таргеты.

## Структура

```
Sources/GXUltraWatch/
  Face/        сегментный движок (7/14 сегментов), тема, стекло, статусная строка,
               движок FaceEngine, снимок данных для осложнений
  Modes/       по файлу на режим
  Services/    HealthKit, CoreMotion, CoreLocation, WeatherKit, датчик воды,
               секундомер, таймер, будильники, тренировка, астрономия
  Intents/     App Intents для кнопки «Действие» и Shortcuts
Sources/GXUltraComplications/  осложнения WidgetKit в том же LCD-стиле
docs/          интерактивный макет циферблата (открывается в браузере)
```

## Что стоит помнить

- Пульс на часах измеряется не непрерывно: в покое интервал может быть 5–10 минут.
  В режиме WKT (тренировка) — раз в несколько секунд.
- Абсолютная высота требует watchOS 15+; иначе показывается высота по GPS.
- Часовой сигнал реализован ежедневными локальными уведомлениями (24 штуки) плюс
  тактильным щелчком, когда экран активен: фоновый доступ к «вибрации по часам»
  Apple не даёт.
